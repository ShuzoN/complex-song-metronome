# メトロノーム — 変拍子・複合拍子の練習用

変拍子・複合拍子を練習するためのメトロノームです。ふつうのメトロノームと違い、
**複数の拍子を並べて1つの「リズムグループ」にまとめ、指定回数くり返し、さらにグループを縦に積んで
曲構成そのものを表現できる**のが特徴です。

たとえば「イントロは 7/8 と 8/8 を4回、A メロは同じ形を8回、サビ前は 4/4 を1回…」といった構成を、
そのままの形で組んで通し再生できます。

**HTML 1ファイルで完結**します。ビルドツール・npm・外部フレームワークは使いません。外部から読み込むのは
Google Fonts と（動画同期時のみ）YouTube IFrame API、（ドラム入力を開いたときのみ）ドラム音源の WebAudioFont だけです。

## 公開ページ

👉 **https://shuzon.github.io/complex-song-metronome/**

ブラウザで開くだけで動きます（インストール不要）。

## 主な機能

- **リズムグループ**：拍子の並び × くり返し回数を1つの区間としてまとめ、縦に積んで曲全体を再生
- **アクセント位置の指定**：グループを開くと拍子ごとに拍のドット（pulse）が並びます。ドットをタップすると
  その拍が **強調音 → 通常音 → ミュート → 強調音** の順に変わります（既定は1拍目のみ強調音。連符を付けた
  拍子では、この切り替えは丸の左に出る拍番号のタップに移ります）。ミュートは破線で表示され、連符の裏拍も含めてその拍全体が無音になります。`7/8` を「1・4・6拍目」で刻むといった
  複合拍子の分け方をそのまま指定でき、アクセントを1つも置かない指定もできます
- **連符（1拍の分割）**：拍子はそのままで「1拍を何分割するか」を 2〜9 から選べます。`4/4` のまま3連符にすれば
  1小節12発、拍の頭は通常のクリック、裏拍は低く小さい音で鳴るので、拍の骨格を見失わずに練習できます。
  拍子の行の「連符」チップをタップすると なし→2→…→9→なし と切り替わります
- **連符のアクセント位置**：連符を付けると、丸ひとつひとつが **クリック（●）⇔ ○（裏拍）** の
  単純な入り切りになります。三連符を ○●○ や ○○● にするだけでなく、**1拍に何個でも置けます**。
  6連符で `●●○○○○`、`●●○○●●` といった刻みがそのまま組めます（全部外せばその拍は裏拍だけになります）。
  位置は**拍ごと**に持つので、同じ小節で 1拍目 ○○● ／ 2拍目 ●○○ のように混ぜられます。
  どの状態でも丸の枠（タップ範囲）の大きさは変わらないので、連打しても丸の位置や並びの幅がずれません。
  どの拍を強調するかの指定（アクセント・ミュート）はこれまでどおり拍単位で、置いた拍の音すべてに乗ります
- **正確な発音**：Web Audio API の先読みスケジューラ方式。分母を音価として扱い、`♩ = BPM` を基準に
  `/8` は倍速、`/16` は4倍速、`/3` は2分3連…と換算
- **グループ無限再生**：「グループ再生」の隣の「∞ 無限再生」で、設定した再生回数ぶんを1周として同じグループを繰り返します。「停止」で終了します。動画同期時は各周で開始位置へ頭出しします。
- **再生速度（speed）**：画面上部の「speed」ボタン（現在の％を表示）からダイアログを開いて設定します。曲のBPMを保持して50〜150％で練習できます。−／＋ボタンは5ポイント刻み、直接入力・上下キー・フォーカス中のホイールは1ポイント刻み。「100％に戻す」でリセットします。個別BPM・到達BPM・無限再生にも適用し、再生中のBPMは拍子表示の横で確認できます。停止しても保持しますが、曲ファイルには保存せず、ページ再読み込み時は100％に戻ります。YouTube同期中も同じ −／＋（5％刻み）で動画の速度を変え、実際の動画速度にメトロノームを合わせます（プレイヤが5％刻みに対応しない場合は、その方向の次の対応速度に切り替えます）。同期を解除すると単体再生の倍率に戻ります。
- **テンポ操作**：スライダー（50〜250、1刻み）／ステッパー（±5・±10）／直接入力（例 `175.5`、入力欄の増減操作は1刻み）／伊語標語（Largo〜Prestissimo）
- **グループBPMの初期値**：「リズムグループを追加」すると、その時点の全体BPMを個別の値として入力・保存します。例えば179 BPMで追加したグループは、全体を185に変えても179のままです。空欄に戻すと全体に追従します。未設定のグループの増減は現在の全体BPMを基準に始まります。
- **線形テンポ変化（到達BPM）**：グループを開くと「追加」ボタンの右に **到達bpm** 欄があります。値を入れると、
  そのリズムグループの先頭から最後の拍にかけて BPM が1拍ずつ線形に変化し、**グループの最後の拍でちょうど到達BPM**になります。
  開始より大きければ加速、小さければ減速。速度を少しずつ上げる練習や、曲中の rit. / accel. をそのまま組めます
- **編集**：グループの追加・複製・削除・ドラッグ並び替え、拍子の追加・並び替え、Undo / Redo
- **拍子の最低数**：各グループには最低1つの拍子が必要です。最後の拍子は削除できません。拍子のない保存データや下書きを読み込むと、4/4拍子を1つ補います。
- **拍子の変更**：グループを開き、既存の拍子の分子・分母を選ぶとその場で変更できます。分子は1〜32、分母は1・2・4・8・16・32です。連符と残る拍の強調音・ミュート設定、連符のアクセント位置は維持されます（拍数が増えた分は拍の頭から始まります）。再生中は変更できません。
- **YAML 保存・読み込み**：曲構成をファイルに書き出し／読み込み（外部ライブラリなしの自前パーサ）
- **YouTube 同時再生**：URL を渡すと動画とメトロノームを同期再生（下記の注意を参照）
- **ドラム入力**：下部の「ドラム入力」から開く別モードです。リズムグループの拍子・くり返し・BPM・到達BPM を
  そのまま使い、各グループにドラムの打点を置けます（下記「ドラム入力」を参照）
- **イヤホン遅延の補正（earphone delay）**：無線イヤホンは機種ごとに音が届くまでの時間が違うため、あるイヤホンで合わせて作った曲ファイルを別のイヤホンで聞くと、動画とクリックがずれます。画面上部（全画面の練習モードでは右下）の「earphone delay」ボタンからダイアログを開き、クリックが遅れて聞こえるときは「早める」、早く聞こえるときは「遅らせる」を押します（10ms刻み。直接入力は −200〜600ms）。テンポは変えずに、クリック全体を同じ時間だけずらします。再生中もその場で反映されます。値はこの端末（ブラウザ）に保存され、YAML には書き込まれません

## 使い方

1. 上の公開ページを開く
2. 「リズムグループ」の拍子を編集・追加し、くり返し回数を決める（新しいグループには4/4拍子が1つ入っています）
3. 必要なら「＋ リズムグループを追加」で区間を積む
4. 左下の **全体再生** で通し再生、右下の **グループ再生** で選択中グループだけを再生
5. スペースキーでも全体再生をトグルできます

### YouTube 同時再生とローカル配信について

YouTube 埋め込みは **http(s) 配信が必須**です。`file://` や `content://`（端末にダウンロードした
HTML を直接開いた場合）では **エラー153** で必ず失敗します（オリジンが `null` になり YouTube 側が
拒否するため。回避策はクライアント側にありません）。

- 公開ページ（GitHub Pages＝https 配信）で開けば問題なく使えます。
- 手元で試すときは、ローカル HTTP サーバー経由で開いてください：

  ```sh
  python3 -m http.server
  # → http://localhost:8000/ を開く
  ```

メトロノーム単体（クリック音のみ）はローカルファイルを直接開いても動きます。

## YAML フォーマット

曲構成は次の形式で保存・読み込みできます（最小例）。

```yaml
version: 1
kind: metronome.sequence

name: アポリア
tempo: 120

groups:
  - name: イントロ
    repeat: 4
    pattern: [7/8, 8/8]
  - name: Aメロ
    repeat: 8
    pattern: [7/8, 8/8]
  - name: サビ前
    repeat: 1
    pattern: [4/4]
  - name: 3連のパート
    repeat: 2
    pattern:
      - meter: 4/4
        accents: [0]
        tuplet: 3        # 4/4 のまま1拍を3分割（1小節12発）
        tupletAccent: 1  # 3分割のうち2つ目に拍の音（全拍 ○●○）
```

- `pattern` は拍子の並び（再生順）。`分子/分母` で書きます。
- 画面で新しく追加する拍子は、分母を `1・2・4・8・16・32`、分子を `1` 〜 `32` から選べます。
- 以前の保存データとの互換性のため、読み込みでは分母・分子とも `1` 〜 `32` を受け付けます（`8/11` などの特殊な拍子も保持します）。
- 分母は音価として扱います。`4` なら4分音符、`8` なら8分音符。慣用の呼び名が無い分母（`11` など）は「全音符÷11」と表示します。
- 読み込みは寛容側：不正な拍子だけを落として件数を報告し、範囲外の値はクランプします。
- 書き出しは常に正規形（コメントや体裁は保存されません）。

アクセント位置を既定（1拍目のみ）から変えたグループは、`pattern` が次の形になります。

```yaml
groups:
  - name: イントロ
    repeat: 4
    pattern:
      - meter: 7/8
        accents: [0, 3, 5]   # 1・4・6拍目にアクセント（0起点）
      - meter: 8/8
        accents: [0]
```

- `accents` は**0起点**の拍番号の配列です（`[0, 3, 5]`＝1・4・6拍目）。
- `tuplet` は**1拍の分割数（連符）**。`2` 〜 `9`、省略または `1` で分割なし。
  `meter: 4/4` ＋ `tuplet: 3` なら 4/4 のまま3連符（1小節12発）になります。小節の長さは変わりません。
  アクセントは分割しても**拍単位**（`accents` は拍番号のまま）で、どの拍を強調するかを表します。
- `tupletAccent` は**連符の中でアクセント（＝拍の音）を鳴らす位置**。**0起点**で、省略すれば
  従来どおり拍の頭です。`tuplet: 3` ＋ `tupletAccent: 1` なら ○●○、`2` なら ○○● になります。
  1拍に複数置けるので、`tuplet: 6` ＋ `[[0, 1]]` なら ●●○○○○、`[[0, 1, 4, 5]]` なら ●●○○●● です。
  次の4通りをどれも読み込めます。

  | 書き方 | 意味 |
  | --- | --- |
  | 省略 | 全拍とも拍の頭（従来のファイル） |
  | `tupletAccent: 1` | 全拍とも2つ目だけ（○●○） |
  | `tupletAccent: [2, 0, 1, 1]` | 拍ごとに1つ（1拍目 ○○● ／ 2拍目 ●○○ ／ 3・4拍目 ○●○） |
  | `tupletAccent: [[0, 1], [0, 1, 4, 5]]` | 拍ごとに複数（1拍目 ●●○○○○ ／ 2拍目 ●●○○●●） |

  書き出しは畳める形から順に選びます（全拍そろっていれば数値 → 全拍とも1つなら数値の配列 →
  複数置いた拍があれば配列の配列）。つまり上の表の形で書いたファイルは、読んで書き戻しても同じ形のままです。
  なお `[0, 1]` のような**数値だけの配列は「拍ごとに1つ」の意味**です（「全拍に2つ置く」と書きたいときは
  `[[0, 1], [0, 1], …]` と拍のぶんだけ並べます）。
- 配列は拍数より短ければ拍の頭（`0`）で埋め、長ければ切り詰めます。範囲外（`0` 未満、分割数以上）や
  数値でない値は落とし、`[]`（空）はその拍に拍の音を置かない＝裏拍だけの拍になります。
  分割なし（`tuplet: 1`）では常に拍の頭だけです。
- `muted: [1, 2]` は2・3拍目をミュート（0起点）。省略するとミュートなし。保存・読み込み・複製でも引き継がれます。
- `accents: []` は「アクセントなし」。省略した拍子・`pattern: [7/8, 8/8]` の従来形式は
  1拍目のみアクセント（既定）として読み込みます。
- 範囲外（`0` 未満、拍数以上）の値は読み込み時に落とします。

### グループごとのテンポと線形テンポ変化

```yaml
groups:
  - name: 通常                 # bpm 省略 = 上部の基準テンポ（tempo）に追従
    repeat: 4
    pattern: [4/4]
  - name: ここだけ速く
    repeat: 4
    bpm: 180                   # このグループだけ 180
    pattern: [4/4]
  - name: だんだん速く
    repeat: 8
    toBpm: 160                 # 基準テンポから 160 へ、グループ全体で線形に加速
    pattern: [4/4]
  - name: 終わりに向けて rit.
    repeat: 2
    bpm: 180
    toBpm: 90                  # 180 から 90 へ線形に減速
    pattern: [4/4]
```

- `bpm` はそのグループの BPM。省略すると `tempo`（上部の基準テンポ）に追従し、再生中にスライダーを
  動かすとそのまま付いてきます。
- `toBpm` は**到達BPM**。指定すると開始BPM（`bpm`、無ければ基準テンポ）から `toBpm` へ、
  グループの総拍数（くり返し込み）を等分して1拍ずつ線形に変化します。**最後の1拍がちょうど `toBpm`** で鳴ります。
- `bpm` / `toBpm` とも `50` 〜 `250`（0.1刻み）。範囲外はクランプ、空・不正な値は「指定なし」として読み込みます。
- テンポ変化中は、下部の拍表示と練習モードに現在の BPM が出ます。

## ドラム入力

下部の「ドラム入力」で開く全画面のモードです。曲の構成（拍子の並び・くり返し・BPM）は
メトロノーム画面のリズムグループがそのまま使われ、ここでは**各グループの打点だけ**を編集します。

- **1グループ＝1パターン（既定は2小節）**：拍子が1つのグループは、その拍子の2回ぶんを1パターンにします。
  `4/4` を `×8` なら「4/4 ×2（2小節）のパターンを ×4」です。拍子が2つ以上（例 `[7/8, 3/4]`）なら並び1回ぶんが1パターンです。
  上部のプルダウンで「1・2・4・8 回ぶん」に変えられ、伸ばすと今のパターンを複製して敷き詰めます（2小節目以降を直してフィルにする等）。
  くり返しがパターンの長さで割り切れないときは、最後はパターンの途中で終わります。
  別の打点にしたい区間は、グループを分けて並べます。
- **打点は拍に付く**：位置は秒ではなく「何拍目のどこ」で持つので、グループBPM・到達BPM・speed・YouTube 同期の
  どれで再生しても拍からずれません。クリックと同じスケジューラで鳴らします。
- **入力**：停止中は STEP 入力（パッドを叩くとカーソル位置に置き、指を離すと1歩進む。歩幅は下のプルダウン）。
  ▶ でそのグループを無限再生、● で再生しながら重ね録り（1回のレックが Undo 1手）。「通し」は全体再生です。
- **編集**：音符をタップして選択 → ←／→ で格子1つぶん移動・削除。五線をなぞると範囲選択（コピー／貼り付け／削除）。
  「自動補正」で、拍ごとに判定した格子（16分・3連など）からずれた打点を吸着させます。
- **拍子の変更**：メトロノーム画面で拍子を変える・並べ替える・消すと、打点は「何小節目の何拍目」に付いたまま移り、
  はみ出した拍の打点は消えます（Undo で戻せます）。
- **設定**：音源（WebAudioFont の GM ドラム／内蔵の合成音）と、タップ補正（叩いてから音になるまでの遅れ）。
  どちらもこの端末に保存し、YAML には書き込みません。タップ補正は earphone delay とは別の値です。
- 「クリック」でメトロノームのクリックを消せます。メトロノーム画面でドラムを鳴らしたくないときは、
  音量の下の「ドラム入力で置いた打点も鳴らす」を外します。

YAML では、打点のあるグループにだけ `drumSpan`（パターンが拍子の並びの何回ぶんか）と `drums` が付きます。
`drums` は楽器ごとに、パターンの先頭からの拍位置を並べます（拍＝その小節の分母の音価。`7/8` なら8分音符1つが1拍）。

```yaml
groups:
  - name: イントロ
    repeat: 2
    pattern: [7/8, 3/4]
    drumSpan: 1
    drums:
      hh_close: [0, 1, 2, 3, 4, 5, 6]
      snare: [2, 5, 8]
      kick: [0, 3, 7, 7.5]     # 7 = 3/4 の1拍目、7.5 = その裏
  - name: Aメロ
    repeat: 8
    pattern: [4/4]
    drumSpan: 2                # 4/4 ×2 ＝ 2小節のパターンを ×4
    drums:
      snare: [1, 3, 5, 7, 7.5] # 4〜7 は2小節目
      kick: [0, 2.5, 4, 6.5]
```

- `drumSpan` は `1` 〜 `8`。省略すると自動（拍子が1つなら `2`、2つ以上なら `1`）。打点を置くと値を固定し、
  あとから拍子を足しても長さ（回数）は変わりません。

- 楽器名は `crash` `effect` `ride` `hh_open` `hh_close` `tom_hi` `tom_low` `snare` `ghost` `rim` `floor` `kick`。
- 位置は叩いたままの値（小数3桁）を保存し、譜面・再生のときに拍ごとに格子へ吸着させます。
- 知らない楽器名、周の外（`0` 未満・拍数以上）の位置は読み込み時に落とします。
- `drums` を知らない以前の版で読み込んで保存すると、打点は消えます。

## バージョニング方針

- `index.html` が常に最新版（公開ページ）です。
- 各バージョン（`v1`〜`v16` …）は聴き比べ・差し戻しのため、作者の手元 `versions/` に保持しています
  （`.gitignore` 済みで公開リポジトリには含みません）。新しい版は旧版を上書きせず番号を進めます。

## 開発とプレビュー（メンテナ向け）

変更は **すべてプルリクエスト経由** で行い、`main` へマージされたものが公開ページになります。

- **本番配信**：`main` に push（PR マージ）されると `deploy.yml` が動き、サイトを `gh-pages`
  ブランチのルートへ配信します。→ https://shuzon.github.io/complex-song-metronome/
- **PR プレビュー**：PR を開く／更新するたびに `preview.yml` が動き、その時点のページを
  `gh-pages` の `pr-preview/pr-<番号>/` へ配信し、PR にプレビュー URL を自動コメントします。
  → `https://shuzon.github.io/complex-song-metronome/pr-preview/pr-<番号>/`
  PR をクローズ／マージすると、そのプレビューは自動で削除されます。

### 一度だけ必要な設定

1. リポジトリを **Public** にする（無料の GitHub Pages に必須）。
2. **Settings → Pages → Build and deployment → Source = Deploy from a branch**、
   Branch = **`gh-pages`** / **`(root)`** を選んで保存。
   （`gh-pages` ブランチは最初のワークフロー実行時に自動作成されます）
3. もし Actions の push が権限エラーになる場合は、**Settings → Actions → General →
   Workflow permissions** を **Read and write permissions** にする。
